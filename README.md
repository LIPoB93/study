# 전기산업기사 스터디 키

개인용 PWA 웹앱입니다.

## 사용 방법
1. 이 폴더 전체를 Vercel, Netlify 또는 GitHub Pages 등에 정적 사이트로 배포합니다.
2. 아이폰 Safari에서 배포 주소를 엽니다.
3. 공유 버튼 → `홈 화면에 추가`를 선택합니다.
4. 앱의 `자료` 메뉴에서 보유한 기본 교재 PDF를 선택합니다.
5. 이후 PART별 `PDF 열기` 버튼을 누르면 관련 페이지로 이동합니다.

## 데이터 보관
- 학습 기록은 브라우저 localStorage에 보관됩니다.
- PDF는 현재 기기의 IndexedDB에 저장됩니다.
- PDF 원본은 이 배포 파일에 포함되어 있지 않습니다.
- 브라우저 데이터를 삭제하면 기록과 PDF가 사라질 수 있으므로, `자료 → 기록 내보내기`로 주기적으로 백업하세요.

## 산업기사 설정
- 업로드된 교재에는 기사 과목인 제어공학이 포함되어 있습니다.
- 전기산업기사 준비에서는 제어공학이 기본 제외되어 있습니다.
- 필요하면 설정 메뉴에서 다시 포함할 수 있습니다.

## 나중에 기출 추가
- `자료 → 산업기사 기출 PDF → 기출 PDF 추가`에서 여러 파일을 추가할 수 있습니다.
- 현재 버전은 기출 PDF 보관과 점수 기록까지 지원합니다.
- 다음 버전에서 연도·회차·문항별 연결을 확장할 수 있습니다.


## Google Sheets 동기화
- 기본 GAS 주소: https://script.google.com/macros/s/AKfycbyjDWSCIZfp_wpJ33QU75cohPsdLH5jAC50uTB1koXeVojP6oHIovbtbhzbeb0Nrk0z/exec
- 설정 메뉴에서 개인 API_KEY를 입력하고 `연결 확인`을 누르세요.
- 아이패드와 아이폰에서 같은 API_KEY를 입력하면 같은 기록을 사용합니다.
- 외부 정적 사이트에서 GAS 데이터를 읽기 위해 GET 응답에 JSONP callback 지원이 필요합니다. 함께 제공된 GAS 패치를 적용하세요.

## 배포 갱신 주의
- 기존 배포에서 파일을 교체한 뒤 Vercel 재배포를 실행하세요.
- Safari에서 이전 화면이 남으면 `?v=3`을 붙여 다시 열고, 홈 화면 아이콘은 삭제 후 재추가하세요.


## 오답 이미지 필기
- 오답 추가 시 문제 이미지를 선택할 수 있습니다.
- 저장 후 `필기` 버튼을 누르면 애플펜슬 또는 손가락으로 풀이를 적을 수 있습니다.
- 문제 이미지와 필기 이미지는 현재 기기의 IndexedDB에 저장됩니다.
- 현재 버전에서는 구글 시트로 이미지가 동기화되지 않습니다. 오답 텍스트와 메타데이터만 동기화됩니다.
