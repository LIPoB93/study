# 전기산업기사 스터디 키 - Flexcil Mode v6

## 역할 분리
- Flexcil: PDF 열람, Apple Pencil 필기, 문제 풀이
- 공부관리 앱: 오늘 페이지 안내, 진도, 타이머, 오답, 출퇴근 암기, 기출 점수
- Google Sheets: 아이패드와 아이폰 기록 동기화

## 적용
GitHub 저장소의 기존 파일을 이 ZIP의 파일로 덮어쓴 뒤 Vercel에서 Redeploy 하세요.
Safari에서는 배포 주소 뒤에 `?v=6`을 붙여 최초 실행하세요.

## 플렉슬 사용
앱에서 `페이지 복사` 또는 `플렉슬로 공부`를 누르면 페이지 범위가 클립보드에 복사됩니다.
외부 웹앱에서 Flexcil의 특정 문서 특정 페이지를 안정적으로 여는 공식 딥링크를 전제로 하지 않습니다.
설정에 단축어 링크를 직접 넣으면 `플렉슬로 공부` 버튼 클릭 후 해당 링크를 실행합니다.

## 동기화
기존 GAS API 및 JSONP 패치를 그대로 사용합니다.
API_KEY는 GitHub에 넣지 말고 각 기기의 설정 화면에서 직접 입력하세요.
